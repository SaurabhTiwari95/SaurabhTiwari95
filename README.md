## Hi, I'm Saurabh 👋

**Solutions Architect · Engineering Manager** · Gurugram, India

I design systems that let AI agents work safely on real business data: secure APIs in front of
existing systems, human approval where it matters, and hard limits on cost. I've spent 8+ years
building and running enterprise platforms on AWS, and I lead an engineering team.

### What I work on

- **AI agents on existing systems:** agents that read and write through governed APIs, with
  guardrails, approvals and cost caps, and no change to the system underneath.
- **Secure API design:** HMAC request signing, single-use nonces, allow-lists, idempotent writes,
  rate caps, circuit breakers, audit logs.
- **AWS:** EC2, RDS (MySQL and PostgreSQL), S3, IAM, KMS, Secrets Manager, SSM, cost optimisation.
- **Engineering leadership:** requirement-to-release process, design reviews, hiring and growing
  engineers.
